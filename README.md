# RadioShare

RadioShare — концепция автономного обмена сообщениями и файлами через mesh-радиосеть без обязательного интернета.

## Сайт

Сайт публикуется через GitHub Pages из ветки `main` после каждого изменения в `client/`. После первого запуска workflow адрес будет иметь вид `https://<владелец>.github.io/radioshare/`.

## Альфа-релиз 0.1.0

Папка `releases/alpha-0.1.0/` содержит portable Windows EXE, debug APK и офлайн-MVP. Нативные исходники находятся в `native/`.

Приложение демонстрирует сообщения, chunk-передачу файлов до 70 ГБ, паузу/продолжение и SHA-256. Реальная LoRa/SDR-передача требует конкретного радиомодуля, драйвера, разрешённых частот и теста между двумя узлами; текущий альфа-релиз использует simulated radio bridge.

## Сборка

Для сайта используйте `pnpm install && pnpm run build`. Для нативных release-сборок смотрите [`native/RELEASE.md`](native/RELEASE.md). Подписывающие ключи не хранятся в репозитории.

## Лицензия и статус

Проект опубликован как alpha / proof of concept. Перед эксплуатацией на радиоэфире проверьте местные нормативы частот, мощности и сертификации оборудования.
